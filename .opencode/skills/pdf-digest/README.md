# PDF通讯稿生成 (pdf-digest)

## 功能简介

从指定的PDF文件中提取内容，整理汇总成一篇结构化的新闻通讯稿或摘要。

## 文件结构

```
pdf-digest/
└── SKILL.md        # 技能定义和工作流
```

## 使用方法

### 1. 触发技能

在opencode中提供PDF文件路径并要求生成通讯稿：

- "帮我总结这个PDF，生成通讯稿: path/to/document.pdf"
- "从这个PDF提取要点并整理成摘要"
- "把这份报告生成一篇新闻通讯稿"

### 2. 支持的输入

- **本地文件路径**：`C:\Documents\report.pdf` 或 `./path/to/file.pdf`
- **URL链接**：`https://example.com/document.pdf`

### 3. 输出选项

通讯稿生成后，可以要求：

- 调整详细程度（精简版/详细版）
- 聚焦特定章节或主题
- 生成不同格式（摘要版/完整版）
- 导出为 `.md` 或 `.txt` 文件

## 前置要求

本技能依赖 **pdfplumber** Python库来提取PDF文本。

### 安装步骤

```bash
pip install pdfplumber
```

安装后即可正常使用PDF提取功能。

## 输出格式示例

生成的通讯稿包含：

- 📋 概览：2-3句话总结
- 📄 基本信息：文档类型、日期、作者等
- 🎯 核心要点：按主题组织的关键内容
- 📊 关键数据：重要统计和数据
- 💡 洞察与建议：分析和解读
- 📌 行动项：后续步骤（如有）
- 📎 原文引用：重要原文摘录

## 注意事项

- **加密PDF**：无法处理加密或受密码保护的PDF
- **扫描件**：图片型PDF需要OCR处理，可能无法直接提取文本
- **大文件**：超过100页的文档建议生成精简版摘要
