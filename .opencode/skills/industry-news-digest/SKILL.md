# 行业新闻通讯稿生成技能

本技能用于从配置的行业网站列表中抓取最新文章，并整理汇总成一篇结构化的新闻通讯稿。

## 配置说明

网站列表存储在配置文件中：`.opencode/skills/industry-news-digest/config.json`

如果配置文件不存在，提示用户创建并提供以下信息：
1. **目标网站列表**：行业网站URL或RSS订阅地址
2. **行业/主题**：聚焦的行业领域
3. **时间范围**：抓取最近几天的文章（默认：7天）

## 工作流

### 步骤 1：读取配置

读取 `config.json` 文件获取网站列表和设置：

```json
{
  "websites": [
    {
      "name": "网站名称",
      "url": "https://example.com",
      "rss": "https://example.com/feed.xml",
      "category": "分类标签"
    }
  ],
  "settings": {
    "dateRange": 7,
    "language": "zh-CN",
    "maxArticlesPerSite": 10,
    "outputFormat": "markdown"
  }
}
```

### 步骤 2：抓取网站内容

优先使用 `webfetch` 工具抓取，当遇到以下情况时改为 `fetch_web.py`：

| 问题 | 解决方案 |
|------|---------|
| 中文乱码（GBK编码站点） | `python fetch_web.py --url <URL> --encoding gbk` |
| HTTPS 412/证书错误 | `python fetch_web.py --url <HTTP版本>` |
| 需要提取文章列表 | `python fetch_web.py --url <URL> --mode articles` |
| 需要批量抓取 | `python fetch_web.py --file urls.txt` |

`fetch_web.py` 完整用法详见 [fetch_web_usage.md](fetch_web_usage.md)。

**JS渲染处理**：如果页面内容依赖JavaScript（SPA架构），尝试以下措施：
1. 查找网站的新闻/政务公开子页面路径（如 `/xwdt/`、`/zwxx/`、`/ggtz/`、`/news/` 等）
2. 查找网站是否有静态版或纯文本版入口
3. 优先建议用户提供RSS订阅地址作为替代

**API逆向**：对于JS渲染的SPA站点，可以下载并分析其JS文件，查找后端API接口地址：
1. 使用 `curl` 下载首页HTML，查找 `<script src="...">` 找到JS入口文件
2. 搜索JS中的关键词：`api`、`axios`、`fetch`、`ajax`、`baseURL`、`url:` 等
3. 如果找到API端点，直接用 `curl` 请求获取JSON数据
4. 将发现的API地址写入配置的 `"api"` 字段中供后续使用
5. 示例：中国电子口岸隐藏API为 `https://www.chinaport.gov.cn/api/newsList?pageNum=1&pageSize=12`

**配置字段扩展**：`config.json` 中的网站条目可包含以下扩展字段：
- `"api"`: 直接可用的数据API接口地址
- `"note"`: 站点访问特性说明

### 步骤 3：处理与筛选

对所有抓取的文章：

1. **去重**：移除跨来源的重复文章
2. **相关性筛选**：保留与行业主题相关的文章
3. **日期筛选**：仅保留指定时间范围内的文章
4. **排序**：按时间和重要性排序

### 步骤 4：生成通讯稿

将筛选后的文章整理成以下格式的通讯稿：

```markdown
# [行业名称] 资讯日报/周报 - [日期范围]

## 📋 概览
用2-3句话总结本期的主要趋势和热点。

## 📰 重点文章

### 1. [文章标题]
**来源**: [网站名称] | **日期**: [发布日期]

[2-3句话的文章摘要]

[阅读全文](URL)

---

### 2. [文章标题]
...

## 🔥 热门话题
- [话题1]: 简要说明为何受到关注
- [话题2]: 简要说明
- [话题3]: 简要说明

## 📊 关键数据
- [文中提到的重要统计数字、数据点]

## 💡 洞察与建议
- [关键洞察1]
- [关键洞察2]
- [关键洞察3]

## 📅 近期动态
- [提及的即将发生的事件、产品发布等]

---
*生成时间：[时间戳] | 数据来源：[抓取的网站列表]*
```

### 步骤 5：输出与优化

1. 向用户展示生成的通讯稿
2. 提供以下选项：
   - 调整语气（更正式/更随意）
   - 调整长度（更精简/更详细）
   - 聚焦特定主题
   - 导出为文件（保存为.md）
   - 使用不同参数重新抓取

## 错误处理

- 如果网站无法访问或返回空内容，在输出中标注并继续处理其他来源
- 如果HTTPS访问失败，自动降级尝试HTTP协议
- 如果页面为JS渲染的SPA，尝试查找子页面路径或建议用户提供RSS订阅地址
- 如果抓取被阻止（如412/403），建议用户提供RSS订阅地址或具体文章页面URL
- 如果找到的文章很少，建议扩大时间范围或添加更多来源

## 优化建议

1. **优先使用RSS**：比HTML页面提供更清晰、结构化的数据
2. **使用具体URL**：直接链接到新闻/博客页面而非首页
3. **添加更多来源**：5-10个来源通常能提供良好覆盖
4. **明确关注点**：越具体的主题筛选越相关
