# PDF通讯稿生成技能

本技能用于从指定的PDF文件中提取内容，并整理汇总成一篇结构化的新闻通讯稿或摘要。

## 前置依赖

本技能需要安装 `pdfplumber` Python库来提取PDF文本。首次使用时，技能会引导安装。

### 安装命令（如未安装）

```bash
pip install pdfplumber
```

## 工作流

### 步骤 1：检查依赖

尝试使用 `pdfplumber` 提取PDF文本。如果失败，引导用户安装：

```bash
pip install pdfplumber
```

### 步骤 2：提取PDF内容

使用Python脚本提取PDF文本：

```python
import pdfplumber
import sys

pdf_path = "path/to/document.pdf"
text = ""

with pdfplumber.open(pdf_path) as pdf:
    for page in pdf.pages:
        page_text = page.extract_text()
        if page_text:
            text += page_text + "\n\n"

print(text)
```

### 步骤 3：内容分析与整理

对提取的文本内容进行分析：

1. **识别文档类型**：报告、白皮书、新闻稿、研究论文、会议资料等
2. **提取关键信息**：
   - 标题/主题
   - 发布日期/时间
   - 作者/机构
   - 核心观点和结论
   - 重要数据和统计
   - 关键事件或行动项
3. **结构化处理**：将内容按主题或章节组织

### 步骤 4：生成通讯稿

将整理后的内容转换为以下格式的通讯稿：

```markdown
# [文档标题/主题] - 内容摘要

## 📋 概览
用2-3句话总结文档的核心内容和目的。

## 📄 基本信息
- **文档类型**：[报告/白皮书/新闻稿等]
- **发布日期**：[日期]
- **作者/机构**：[名称]
- **页数/字数**：[如可获取]

## 🎯 核心要点

### 1. [要点标题]
[2-3句话的详细说明]

### 2. [要点标题]
[2-3句话的详细说明]

### 3. [要点标题]
[2-3句话的详细说明]

## 📊 关键数据
- [重要统计数据1]
- [重要统计数据2]
- [重要统计数据3]

## 💡 洞察与建议
- [关键洞察1]
- [关键洞察2]
- [关键洞察3]

## 📌 行动项/后续步骤
- [如有提及的行动建议或后续计划]

## 📎 原文引用
> [选取1-2段原文中的重要引述]

---
*从PDF文件 [文件名] 生成 | 处理时间：[时间戳]*
```

### 步骤 5：输出与优化

1. 向用户展示生成的通讯稿
2. 提供以下选项：
   - 调整详细程度（精简版/详细版）
   - 聚焦特定章节或主题
   - 生成不同格式（摘要版/完整版）
   - 导出为 `.md` 或 `.txt` 文件

## 错误处理

- **缺少依赖**：提示用户运行 `pip install pdfplumber` 安装
- **PDF加密**：无法处理加密或受密码保护的PDF，告知用户
- **扫描件**：图片型PDF无法直接提取文本，建议使用OCR工具
- **大文件**：超过100页的文档建议生成精简版摘要

## 示例用法

用户："帮我总结这个PDF文件的内容，生成一篇通讯稿"
用户路径："path/to/report.pdf"

Agent应：
1. 检查是否安装 `pdfplumber`
2. 使用Python提取PDF文本
3. 分析并整理核心要点
4. 生成结构化的通讯稿
5. 以中文输出（匹配用户语言）
