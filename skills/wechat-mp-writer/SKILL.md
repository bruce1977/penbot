# 公众号文章撰写 Skill

## 变量说明

| 变量 | 来源 | 说明 |
|------|------|------|
| `{topic}` | `selected-topic.md` 或 `{topic_plan}.json` 中的主题名 | 用于输出文件命名，如 `大模型` |
| `{output}` | coordinator 下发的输出根目录 | 如 `output/test/20260711` |
| `{knowledge-local}` | coordinator 下发的本地知识库目录 | 如 `.knowledge/test` — 可选，与 `{knowledge-remote}` 至少提供一个 |
| `{knowledge-remote}` | 未来预留：远程知识库接口 | 与 `{knowledge-local}` 并列，均为可选；至少提供一个即可 |
| `{output_path}` | 自动拼接 | `{output}/{topic}_proofed.md` |

## 输入与输出

| | |
|------|------|
| **输入 (1)** | `{output}/selected-topic.md`（完整管线）或 `{topic_plan}.json`（写稿管线）— 选题说明 + 配图构想 |
| **输入 (2)** | `{knowledge-remote}` — 远程知识库接口（预留，与 `{knowledge-local}` 并列，至少提供一个） |
| **输入 (3)** | `web-search` 搜索补充素材的返回结果 |
| **输入 (4)** | `{output}` — 文章保存的目标目录 |
| **输出** | `{output}/{topic}_proofed.md` — 经过 3 轮审稿的 Markdown 文件，含 frontmatter `title` + 正文（含 `[图：图片说明]` 标记） |

## 执行步骤

### 1. 读取经验

写作前先读取 `agents/experience/writer.md`，查阅历史经验教训，避免重复犯错。

### 2. 阅读素材

阅读全部输入素材，建立对主题的完整理解：

- `{topic_plan}.json` 或 `{output}/selected-topic.md` — 选题说明 + 配图构想
- `{knowledge-local}`（如提供）和/或 `{knowledge-remote}`（如提供）— 知识库素材
- `web-search` 返回的补充素材

### 3. 拟定大纲

- 确定文章类型（资讯快评 / 技术解读 / 行业分析 / 深度观点 / 轻松科普）
- 规划结构：开篇 → 分段论述 → 结尾
- 标注配图位置，插入 `[图：图片说明]` 标记（封面 1 张 + 文中 **1-2 张**，说明 **30-120 字**，图片说明须与 `{topic_plan}.json` 中 `illustrations` 数组的定义一致）

### 4. 撰写初稿

- 按大纲撰写完整 Markdown 文章
- 使用 `web-search` 按需补充素材
- 生成 frontmatter：
  ```yaml
  ---
  title: {文章标题}
  ---
  ```

### 5. 3 轮审稿

**第 1 轮 — 内容与结构**：完整性、逻辑、数据准确性、观点一致性 → 修正

**第 2 轮 — 表达与风格**：标题吸引力、段落节奏、语言风格、配图合理性、金句提炼 → 修正

**第 3 轮 — 校对**（调用 `proofreader` subagent）：
- 敏感词检查 → 错别字/语法修正 → 语病/标点复核 → 逻辑复查 → 图片说明字数校验
- **检查图片语法**：确保文中所有图片均为 Markdown `![说明](路径)` 格式，无残留的 `<img>` / `<Image>` HTML 标签。发现 HTML 标签立即替换为等价的 Markdown 语法
- 发现问题则修正，可多次调用验证直至无误

### 6. 输出终稿

写入 `{output}/{topic}_proofed.md`，包含：
- frontmatter `title`
- 正文（含 `[图：图片说明]` 标记）
- 信息源标注

### 7. 记录经验

将本次经验教训追加到 `agents/experience/writer.md`。

## 写作规范

### 按文章类型的要求

**资讯快评**（800-1200字）
- 时效性优先，开篇直击要点
- 夹叙夹议，观点鲜明
- 结尾可做趋势预判或留开放式问题

**技术解读**（1200-2000字）
- 由浅入深，多用类比
- 术语首次出现加括号注释
- 关键数据/架构配图说明

**行业分析**（1500-2500字）
- 数据驱动，逻辑严密
- 覆盖技术、市场、政策、竞争等多维度
- 结论清晰，引用标注来源

**深度观点**（1500-2000字）
- 围绕一个核心观点展开
- 每段 1-2 句可传播的亮点句
- 结尾升华到普遍规律或行动建议

**轻松科普**（800-1500字）
- 故事化开头，语言生动
- 每篇传递 1-2 个核心知识点
- 段落短小，适配零碎阅读

### 语言规范
- 段落 ≤5 行（手机适配）
- 引用数据或观点时注明来源
- 适当使用序号列表、加粗、引用格式
