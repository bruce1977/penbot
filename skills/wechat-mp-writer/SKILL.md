# 公众号文章撰写 Skill

## 执行步骤

### 步骤 0：读取经验池（自我提升）

写作前先读取 `agents/experience/writer.md`，查阅历史经验教训，避免重复犯错，借鉴过往成功做法。

### 步骤 1：阅读素材

阅读 coordinator 下发的全部素材，建立对主题的完整理解：

- `selected-topic.md` — 选题说明、中选理由、评分对比
- 相关公众号文章原文（`{output}/../*.md`）
- web-search 补充素材

### 步骤 2：拟定大纲

- 确定文章类型和风格定位（资讯快评 / 技术解读 / 行业分析 / 深度观点 / 轻松科普）
- 规划结构：开篇 → 分段论述 → 结尾
- 标注配图位置，在关键位置插入 `[图：图片说明]` 标记
- 配图数量：封面 1 张 + 文中 **1-2 张**，图片说明 **30-120 字**

### 步骤 3：撰写初稿

- 按大纲撰写完整文章
- 在关键位置（数据对比、流程示意、核心观点可视化）插入 `[图：图片说明]` 标记
- 使用 `web-search` 按需搜索补充素材并引用
- 输出为 Markdown 格式

### 步骤 4：3 轮审稿循环

#### 第 1 轮 — 内容与结构审稿

检查以下方面，发现问题逐条修正：

| 检查项 | 说明 |
|--------|------|
| 内容完整性 | 是否覆盖选题所有核心要点，有无重要遗漏 |
| 逻辑连贯性 | 段落衔接是否自然，论点→论据→结论链条是否完整 |
| 数据准确性 | 数字、日期、名称是否准确，引用是否可追溯 |
| 观点一致性 | 全文立场是否统一，前后有无自相矛盾 |

修正后进入第 2 轮。

#### 第 2 轮 — 表达与风格审稿

检查以下方面，发现问题逐条修正：

| 检查项 | 说明 |
|--------|------|
| 标题吸引力 | 是否包含关键词、制造悬念或价值承诺 |
| 段落节奏 | 每段是否 ≤5 行，手机阅读体验是否流畅 |
| 语言风格 | 是否匹配题材类型（通俗/专业/轻松），有无过度学术化或口语化 |
| 配图合理性 | `[图：图片说明]` 的位置是否合适，说明文字是否 30-120 字 |
| 金句提炼 | 是否有可传播的亮点句，结尾是否有力 |

修正后进入第 3 轮。

#### 第 3 轮 — 校对审稿（调用 proofreader）

调用 `proofreader` subagent 进行技术校对：

- 敏感词检查（`word-sensitive-check` 技能）
- 错别字/语法修正（`word-corrector-check` 技能）
- 语病/标点复核
- 逻辑一致性复查
- 图片说明字数校验

proofreader 返回问题清单后逐条修正。若问题较多可再次调用验证，确保最终输出无误。

### 步骤 5：输出终稿

输出校对完成的文章到 `{output}/{topic}_proofed.md`，包含：
- 标题
- 正文（含 `[图：图片说明]` 标记）
- 信息源标注

### 步骤 6：记录经验（持续改进）

任务完成后将本次写作的经验教训追加到 `agents/experience/writer.md`，内容包括：
- 文章类型与主题
- 做得好的地方（可复用的成功做法）
- 遇到的问题与原因
- 改进措施与下次注意事项

> 经验记录越具体越有价值。例如："技术解读类文章，读者对架构图配图反馈好，后续同类文章应增加流程示意图"而非笼统的"配图要更好"。

## 写作规范

### 题材与风格（按类型区分要求）

不同文章类型对写作有不同要求，拟定大纲和撰写时须按以下规范匹配：

**资讯快评**（800-1200字）
- 时效性优先，紧扣最新事件或数据
- 开篇直击要点，用 1-2 句话交代背景+核心判断
- 夹叙夹议，事实陈述与观点评论穿插
- 观点鲜明，避免模棱两可的表述
- 结尾简短有力，可做趋势预判或留开放式问题

**技术解读**（1200-2000字）
- 由浅入深：从读者熟悉的场景切入，逐步深入到技术细节
- 多用类比：将复杂技术概念映射到日常生活场景
- 关键数据/架构配图说明，避免大段纯文字描述
- 术语首次出现时加括号注释，降低阅读门槛
- 技术细节准确，不夸大效果，注明适用范围

**行业分析**（1500-2500字）
- 数据驱动：关键论点必须有数据或案例支撑
- 逻辑严密：现象→原因→影响→趋势，链条完整
- 多维度分析：覆盖技术、市场、政策、竞争等视角
- 结论清晰：给出明确的判断或建议，避免"既要……又要……"
- 引用标注来源，增强可信度

**深度观点**（1500-2000字）
- 论点鲜明：全文围绕一个核心观点展开，不散不偏
- 论据充分：结合数据、案例、行业动态分层论证
- 有金句提炼：每段应有 1-2 句可独立传播的亮点句
- 敢于表态：在充分论证基础上给出明确立场
- 结尾升华：从具体现象上升到普遍规律或行动建议

**轻松科普**（800-1500字）
- 故事化开头：用趣事、历史、冷知识吸引注意力
- 语言生动：多用比喻、拟人、设问等修辞手法
- 知识密度适中：每篇文章传递 1-2 个核心知识点即可
- 避免堆砌术语，必须用的术语要做通俗解释
- 段落短小精炼，适配零碎阅读场景

### 文章结构

```
标题：吸引点击，包含关键词，制造悬念或价值承诺

开篇（100-200字）：
- 从读者熟悉的话题切入
- 用数据/故事/问题引发共鸣
- 快速交代文章要解决什么问题

正文（分段小标题）：
- 每段 200-400 字，配合空行分隔
- 小标题提炼核心观点
- 数据/案例穿插其中增强说服力
- 适当使用加粗强调关键句

结尾（100-150字）：
- 总结核心观点
- 引导互动（提问/转发/关注引导）
- 金句收尾，增强传播力
```

### 语言规范
- **段落**：每段不超过 5 行（手机屏幕适配）
- **引用**：引用数据或他人观点时注明来源
- **原创性**：在素材基础上二次加工，杜绝抄袭
- **可读性**：适当使用序号列表、加粗、引用格式
